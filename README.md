# Language Notes

```
x = ½ √( 2 + u² - v² + 2u√2 ) - ½ √( 2 + u² - v² - 2u√2 )
y = ½ √( 2 - u² + v² + 2v√2 ) - ½ √( 2 - u² + v² - 2v√2 )
```

```
in u, v

x = 0.5 * sqrt( 2 + u^2 - v^2 + 2 * u * sqrt( 2 ) ) - 0.5 * sqrt ( 2 + u^2 - v^2 - 2 * u * sqrt( 2 ) )
y = 0.5 * sqrt( 2 - u^2 + v^2 + 2 * v * sqrt( 2 ) ) - 0.5 * sqrt ( 2 - u^2 + v^2 - 2 * v * sqrt( 2 ) )

out x, y
```
